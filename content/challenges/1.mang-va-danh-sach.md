# 📔 Day 1: Dynamic Array

## Giới thiệu

Mảng động là vùng nhớ liên tục có dự trữ chỗ trống. Hết chỗ thì cấp vùng gấp đôi và sao chép sang. Bài này chỉ học một thứ: tự cài đặt Dynamic Array.

## Kiến thức cần nhớ

### Size vs capacity

- `size`: số phần tử đang dùng.
- `capacity`: số ô đã cấp phát.
- `size == capacity` khi `push` → phải cấp phát lại.

### Vì sao nhân đôi

Cấp vùng mới gấp đôi, copy toàn bộ, rồi mới thêm. Nhờ dự trữ dư nên n lần `push` chỉ tốn $O(1)$ trung bình.

### Bảng độ phức tạp

| Thao tác | Độ phức tạp | Lý do |
| --- | --- | --- |
| `get/set` theo chỉ số | $O(1)$ | tính địa chỉ trực tiếp |
| `push/pop` cuối | $O(1)$ trung bình | thỉnh thoảng copy khi đầy |
| `insert/erase` giữa | $O(n)$ | phải dồn phần tử giữ liên tục |
| `reserve/shrink` | $O(n)$ | cấp mới + copy một lần |

### Khung struct

```c
// C
typedef struct {
  int *data;
  int size;
  int capacity;
} DynamicArray;
```

```cpp
// C++: class DynamicArray với data_, size_, capacity_ + destructor
```

Quy tắc bắt buộc:

- `realloc` qua con trỏ tạm, thất bại thì mảng cũ còn nguyên.
- Mọi `get/set/insert/erase/pop` kiểm tra biên, không crash.
- `destroy` free đúng 1 lần, gán `NULL`, không leak.

## Ví dụ

```c
DynamicArray a; da_init(&a, 2);
da_push(&a, 1); da_push(&a, 2); da_push(&a, 3);
// capacity: 2 -> 4, size = 3
da_get(&a, 1);    // = 2
da_insert(&a, 1, 9); // 1, 9, 2, 3
da_erase(&a, 1);     // 1, 2, 3
da_pop(&a);          // 1, 2
da_destroy(&a);
```

## 💻 Bài tập

1. Khởi tạo capacity 2, `push` 10 phần tử. Ghi lại vết capacity (phải ra 2 → 4 → 8 → 16), kiểm tra `size` và dữ liệu còn nguyên.
2. `push` 1, 2, 3 → `get(1)` phải bằng 2. `insert(1, 9)` → 1, 9, 2, 3. `erase(1)` → 1, 2, 3. `pop` → 1, 2.
3. Thử `get/set/insert/erase` ngoài biên và `pop` khi rỗng. Chương trình phải báo lỗi, không crash.
4. Chạy với sanitizer hoặc valgrind: không leak, không double-free, không use-after-free.
5. Giải thích miệng: vì sao nhân đôi cho `push` $O(1)$ trung bình, còn tăng từng ô một thì thành $O(n^2)$.

## ❓ Câu hỏi ôn tập

- `size` khác `capacity` ở điểm nào? Khi nào phải cấp phát lại?
- Vì sao `push` cuối là $O(1)$ trung bình nhưng `insert` giữa là $O(n)$?
- Vì sao `realloc` phải qua con trỏ tạm?
- Khi nào dùng `reserve`, khi nào dùng `shrink_to_fit`?
