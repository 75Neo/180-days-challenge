## Giới thiệu

Bài này học cách thêm topping mà không làm vỡ các lớp cũ. Ý tưởng chính là bọc từng đối tượng bằng một lớp khác, giống như búp bê Nga.

## Kiến thức cần nhớ

### Vấn đề của kế thừa

- Mỗi tổ hợp topping cần một lớp riêng, nên số lớp bùng nổ.
- Nếu nhét hết vào lớp cha thì lớp cha sẽ phình to.
- Mỗi khi thêm topping mới, bạn lại phải sửa code cũ.
- Ví dụ đời thường: in một thực đơn riêng cho mọi combo.

### Chuỗi bọc cộng dồn

- Mỗi topping bọc lấy đồ uống ở bên trong.
- Khi hỏi giá, topping sẽ hỏi lớp bên trong trước, rồi cộng thêm phần giá của mình.
- Khi hỏi mô tả, topping nối thêm tên của mình vào mô tả bên trong.
- Ví dụ đời thường: hộp quà lồng nhau, mở từng lớp ra.
- Muốn thêm topping mới, bạn chỉ cần thêm một lớp bọc mới.

### Khi nào bọc, khi nào không

- Khi cần gắn thêm hành vi cho từng món riêng lẻ thì nên bọc.
- Khi số combo quá lớn, không thể liệt kê hết thì nên bọc.
- Nếu chỉ có 2-3 combo cố định thì liệt kê thẳng ra là đủ.
- Ví dụ đời thường: dán sticker lên từng cái cốc riêng.

| Cách làm | Khi thêm topping mới |
| --- | --- |
| Mỗi combo 1 lớp | Số lớp nhân đôi |
| Cờ ở lớp cha | Phải mở lớp cha ra sửa |
| Chuỗi bọc | Chỉ thêm 1 lớp mới |

## Ví dụ

- Đầu vào: cà phê đậm và 1 phần sữa. Kết quả: giá nền cộng thêm giá sữa, mô tả có đủ hai món.
- Giải thích: lớp sữa hỏi giá của lớp lõi bên trong, rồi cộng thêm phần của mình.

## 💻 Bài tập

Ngôn ngữ: **C++17** (hoặc Java). Nộp vào thư mục `day-012/`. Giá tính bằng đồng, kiểu `long long`.

### Bài 1: Starbuzz Coffee

```cpp
class Beverage {
 public:
  virtual std::string description() const = 0;
  virtual long long cost() const = 0;
  virtual ~Beverage() = default;
};
class CondimentDecorator : public Beverage {
 protected:
  std::unique_ptr<Beverage> inner;
 public:
  explicit CondimentDecorator(std::unique_ptr<Beverage> b);
};
```

Hãy cài đặt các lớp đồ uống và topping theo bảng sau:

| Lớp | Giá | Mô tả |
| --- | --- | --- |
| `Espresso` | 30.000 | `"Espresso"` |
| `HouseBlend` | 25.000 | `"House Blend"` |
| `DarkRoast` | 28.000 | `"Dark Roast"` |
| `Milk` | +5.000 | nối thêm `", Sữa"` |
| `Mocha` | +7.000 | nối thêm `", Mocha"` |
| `Soy` | +6.000 | nối thêm `", Sữa đậu nành"` |
| `Whip` | +4.000 | nối thêm `", Kem"` |

```text
DarkRoast + Mocha + Mocha + Whip  -> "Dark Roast, Mocha, Mocha, Kem" = 46000
Espresso                          -> "Espresso" = 30000
HouseBlend + Soy + Mocha + Whip   -> 42000
```

### Bài 2: Size ly và thêm topping mới

1. Thêm `enum class Size { Small, Medium, Large }` vào `Beverage`. Các topping sẽ lấy size từ đồ uống bên trong (`inner`).
2. `Soy` tính giá theo size: nhỏ 4.000, vừa 6.000, lớn 8.000.
3. Thêm `Caramel` (+9.000) chỉ bằng một file mới.

```text
Espresso(Large) + Soy -> 38000
Espresso(Small) + Soy + Caramel -> 43000
```

### Bài 3: Vé xem phim và decorator vào-ra (nâng cao)

1. `Ticket` gốc có giá 90.000. Có 3 decorator: `WeekendSurcharge` (+20%), `ThreeD` (+30.000), và `StudentDiscount` (-15%). Thứ tự bọc làm thay đổi giá cuối cùng. Hãy tính và giải thích kết quả của 2 thứ tự khác nhau.
2. Viết interface `TextSource { virtual std::optional<char> read() = 0; }`. Sau đó viết `StringSource` và hai decorator: `UpperCase` (đổi chữ thường thành chữ hoa) và `SkipSpaces` (bỏ khoảng trắng).

```text
UpperCase(SkipSpaces(StringSource("a b c"))) đọc hết -> "ABC"
SkipSpaces(UpperCase(StringSource("x y")))   đọc hết -> "XY"
```
