# 📔 Day 131: Ngày 131 — App: recommendation engine end-to-end

## Giới thiệu
Bài này xây máy gợi ý phim và sản phẩm. Người cũ gợi theo gu, người mới gợi theo top phổ biến.

## Kiến thức cần nhớ

### Content-based theo metadata
- Vector hóa thể loại và mô tả bằng TF-IDF.
- Profile user là trung bình vector các item đã thích.
- Gợi ý bằng cosine giữa profile và item chưa xem.
- Ví dụ đời thường: thích phim hành động thì gợi thêm phim hành động.

### Collaborative filtering theo đám đông
- User-based: người giống bạn thích gì thì gợi nấy.
- Item-based: ai thích món này cũng thích món kia.
- Cần đủ rating chung mới tin, ít quá thì rất nhiễu.
- Ví dụ đời thường: bạn cùng gu khen hay thì bạn cũng thấy hay.

### Matrix factorization và cold start
- Phân rã ma trận rating thành 2 ma trận latent user và item.
- Dự đoán bằng tích vô hướng 2 vector latent.
- User mới thì gợi phổ biến cộng theo thể loại đăng ký.
- Item mới chỉ có metadata thì đi nhánh content-based.

| Mô hình | Cần gì | Mạnh khi nào |
|---|---|---|
| Content-based | Metadata item | Item mới, user ít lịch sử |
| CF | Rating chung | User cũ đông |
| Factorization | Nhiều rating | Gu ẩn phức tạp |

## Ví dụ
- Input: user mê hành động, hỏi top-10. Output: trên 60% phim hành động, không chứa phim đã xem.
- Giải thích: cosine đẩy phim cùng thể loại lên đầu, bộ lọc bỏ phim đã xem.
- Input: user mới tinh vừa đăng ký. Output: danh sách phổ biến theo thể loại đã chọn.
- Giải thích: chưa có lịch sử nên đi nhánh cold start.

## 💻 Bài tập
1. Nạp MovieLens nhỏ, chia train test theo thời gian, tính sparsity. Kiểm tra: báo cáo sparsity và baseline phổ biến.
2. Cài content-based và CF item-based, đo precision at 10. Kiểm tra: ghi 2 con số để so nhau.
3. Cài factorization SGD, so RMSE với trung bình toàn cục. Kiểm tra: RMSE thấp hơn ít nhất 15%.
4. Cài bộ lai và nhánh cold start cho user và item mới. Kiểm tra: user mới không bao giờ trả rỗng.
5. Đo precision at 10 và độ đa dạng thể loại. Kiểm tra: precision trên 0.2, thể loại distinct trên 3.

## ❓ Câu hỏi ôn tập

- Cold start xử lý user và item mới ra sao?
