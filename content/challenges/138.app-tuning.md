## Giới thiệu

Bài này học chỉnh model cho vừa đẹp. Nhỏ quá thì dốt, lớn quá thì học vẹt.

## Kiến thức cần nhớ

### Gradient descent học tham số

- Tham số là số trong model, học bằng bước ngược gradient.
- Learning rate lớn quá thì phân kỳ, nhỏ quá thì lì.
- Log loss mỗi epoch để vẽ đường cong học.
- Ví dụ đời thường: xuống núi đi bước vừa chân, bước dài quá thì ngã.

### Grid và random search

- Siêu tham số là số ngoài model như độ sâu cây.
- Grid search vét hết lưới, random search bốc ngẫu nhiên.
- Cùng 20 trial thì random hay thắng vì ít siêu tham số quan trọng.
- Mỗi trial chấm bằng cross-validation 3-fold cho chắc.

### Chống overfit khi eval

- Chia train, validation, test theo 60-20-20 có seed.
- Chọn cấu hình trên validation, đo test đúng 1 lần cuối.
- Train tốt mà validation tệ là overfit học vẹt.
- Điểm train cao hơn hẳn validation là dấu hiệu overfit; khoảng cách nhỏ và ổn định qua các fold mới đáng tin.

```python
# Vòng tuning gọn
for params in search(20):  # grid hoặc random 20 trial
    score = cross_val(params, train)  # chấm CV 3-fold
    log(params, score)  # ghi nhật ký
best = pick_best()  # chốt trên validation
test_once(best)  # đo test đúng 1 lần
```

## Ví dụ

- Input: hồi quy tuyến tính với 3 learning rate. Output: rate vừa cho loss giảm đều, rate lớn gây phân kỳ.
- Giải thích: bước quá dài nhảy qua đáy nên loss nổ tung.
- Input: cây quá sâu. Output: train tốt, validation tệ, gap lớn.
- Giải thích: cây nhớ vẹt từng điểm train nên không tổng quát.
