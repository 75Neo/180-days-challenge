# 📔 Day 140: Ngày 140 — App: tìm ảnh với CNN và similarity search

## Giới thiệu
Bài này xây app tìm ảnh giống nhau. Tải 1 ảnh mèo lên là ra thêm nhiều ảnh mèo.

## Kiến thức cần nhớ

### Đặc trưng CNN pretrained
- Dùng CNN có sẵn, cắt đầu phân loại lấy vector giữa.
- Chuẩn hóa L2 để so cosine thành tích vô hướng.
- Không cần huấn luyện lại từ đầu nên rất rẻ.
- Ví dụ đời thường: mượn mắt thợ ảnh chuyên nghiệp để mô tả ảnh.

### 2 bản index nhanh và chuẩn
- Brute-force so với hết mọi ảnh làm chuẩn đúng.
- K-d tree chia không gian để tìm lân cận nhanh hơn.
- Chiều rất cao 512+ thì k-d tree có thể thua brute-force.
- Phải đo thực tế thay vì tin lý thuyết suông.

### Đo chất lượng tìm kiếm
- Precision at K: trong K ảnh trả về có mấy ảnh đúng lớp.
- Recall: bản nhanh bắt được bao nhiêu so với bản chuẩn.
- Ghi bảng theo từng lớp để lộ lớp khó dễ nhầm.
- Mục tiêu mẫu: precision trên 0.7, recall trên 0.95.

## Ví dụ
- Input: ảnh mèo hỏi top-10. Output: trên 7 ảnh mèo trong kết quả.
- Giải thích: vector mèo gần nhau nên lân cận toàn mèo.
- Input: 200 query so 2 index. Output: k-d tree recall trên 0.95, nhanh gấp 3 lần.
- Giải thích: gần đúng bỏ chút chính xác để đổi tốc độ.

## 💻 Bài tập
1. Nạp 5 nghìn ảnh, resize chuẩn hóa, trích thử 100 vector. Kiểm tra: shape vector đồng nhất.
2. Xây index brute-force, test 20 query tay. Kiểm tra: ảnh mèo trả về toàn mèo.
3. Xây k-d tree, đo recall so brute-force trên 200 query. Kiểm tra: recall trên 0.95.
4. Đo p95 cả 2 index trên 5 nghìn vector. Kiểm tra: k-d tree nhanh hơn ít nhất 3 lần.
5. Đo precision theo từng lớp, viết demo upload. Kiểm tra: báo cáo nêu lớp khó thấp điểm riêng.

## ❓ Câu hỏi ôn tập
- Vì sao dùng CNN pretrained thay vì train mới?
- Chuẩn hóa L2 giúp so ảnh thế nào?
- Brute-force làm chuẩn vàng để làm gì?
- Precision at K và recall mỗi cái đo điều gì?
