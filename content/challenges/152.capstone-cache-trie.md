## Giới thiệu

Bạn nâng gợi ý từ khóa nhanh hơn. Cache giúp câu hỏi lặp trả lời ngay.

## Kiến thức cần nhớ

### Trie và radix trie

- Trie là cây tiền tố, tìm gợi ý theo từng ký tự.
- Radix trie nén chuỗi chung, tiết kiệm bộ nhớ hơn.
- Ví dụ đời thường: giống mục lục từ điển theo vần.
- Tìm kiếm mỗi từ tốn theo độ dài từ.

### LRU và LFU

- LRU đuổi mục lâu chưa dùng nhất.
- LFU đuổi mục ít dùng nhất.
- Ví dụ đời thường: LRU như dọn đồ lâu không đụng, LFU như bỏ đồ ít dùng.
- Chọn LRU khi thói quen mới, LFU khi thói quen ổn định.

### Cache và SLO p95

- Cache lưu kết quả cũ để trả lời nhanh.
- Định nghĩa p95: 95% request nhanh hơn ngưỡng này.
- Ví dụ đời thường: p95 như cam kết 95 đơn giao đúng giờ.
- Đo p95 thay vì chỉ đo trung bình.

```python
# cache đơn giản bằng dict
cache = {}  # nơi lưu kết quả cũ
def goi_y(tu):
    if tu in cache:  # đã hỏi rồi
        return cache[tu]  # trả ngay
    kq = ["gợi ý 1"]  # tính mới ở đây
    cache[tu] = kq  # lưu lại
    return kq
```

## Ví dụ

- Input `"app"` -> output `["apple", "app"]` vì cùng tiền tố.
- Hỏi `"app"` lần hai trả ngay từ cache.
