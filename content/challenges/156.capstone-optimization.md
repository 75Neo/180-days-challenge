# 📔 Day 156: tối ưu TSP và vẽ đồ thị tổng hợp
## Giới thiệu
Bạn tìm đường thăm mọi thành phố ngắn nhất. Thử nhiều cách rồi so kết quả.
## Kiến thức cần nhớ
### TSP là gì
- TSP là đi qua mọi thành phố rồi về chỗ cũ.
- Định nghĩa: tìm tour ngắn nhất, bài toán khó nổi tiếng.
- Ví dụ đời thường: giống shipper đi mọi điểm rồi về kho.
- Thử mọi cách chỉ hợp khi thành phố ít.
### Brute-force, greedy và DP
- Brute-force thử mọi tour, đúng nhưng rất chậm.
- Greedy mỗi bước đi tới thành phố gần nhất.
- Ví dụ đời thường: greedy như luôn chọn quán gần nhất.
- DP nhớ kết quả con nên nhanh hơn brute-force.
### Heuristic và 2-opt
- Heuristic là cách gần đúng, nhanh nhưng không chắc tốt nhất.
- 2-opt gỡ hai đoạn chéo nhau để tour ngắn lại.
- Ví dụ đời thường: 2-opt như gỡ dây rối cho gọn.
- Vẽ ít giao cắt giúp nhìn tour rõ hơn.
```python
# độ dài một tour
def do_dai(tour, xa):
    tong = 0  # cộng dồn quãng đường
    for i in range(len(tour)):
        a = tour[i]  # điểm hiện tại
        b = tour[(i + 1) % len(tour)]  # điểm tiếp theo
        tong += xa[a][b]  # cộng đoạn này
    return tong
```
## Ví dụ
- Input 4 thành phố -> brute-force thử mọi tour rồi chọn ngắn nhất.
- Tour bị chéo nhau -> 2-opt gỡ chéo cho ngắn lại.
## 💻 Bài tập
1. Viết brute-force cho TSP 6 thành phố.
   Kiểm tra: tour ra ngắn nhất đúng.
2. Viết greedy láng giềng gần nhất trên cùng dữ liệu.
   Kiểm tra: so độ dài với brute-force.
3. Áp 2-opt lên tour greedy.
   Kiểm tra: tour mới ngắn hơn hoặc bằng.
4. Thử simulated annealing 100 vòng.
   Kiểm tra: ghi tour tốt nhất tìm được.
5. Vẽ tour đẹp nhất, đếm số giao cắt.
   Kiểm tra: hình vẽ rõ, ghi số giao cắt.
