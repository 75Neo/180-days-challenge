## Kiến thức cần nhớ

### Duyệt và biến đổi BST

- BST là trái nhỏ hơn gốc, phải lớn hơn gốc.
- Hay gặp: liệt kê trong khoảng, tìm tổ tiên chung.
- Ví dụ đời thường: giống tìm sách trong kệ xếp theo tên.
- Cắt tỉa bỏ nhánh ngoài khoảng cho nhanh.

### Kiểm tra BST hợp lệ

- So cha con thôi là chưa đủ.
- Phải dùng khoảng chặn từ gốc truyền xuống.
- Ví dụ đời thường: giống kiểm tra cả dòng họ, không chỉ cha con.
- Nút sai ở tầng sâu dễ lọt nếu chỉ so gần.

### Heap và top-k

- Heap lấy lớn nhất hoặc nhỏ nhất rất nhanh.
- Heapify biến mảng thành heap trong $O(n)$.
- Ví dụ đời thường: heap như xếp hàng ưu tiên.
- Top-k trên stream chỉ giữ k món, không giữ hết.

```python
# top-k nhỏ nhất bằng heap
import heapq  # thư viện heap sẵn
def topk(a, k):
    h = []  # heap giữ k món
    for x in a:  # duyệt từng món
        heapq.heappush(h, x)  # đẩy vào heap
        if len(h) > k:  # quá k món
            heapq.heappop(h)  # bỏ món nhỏ nhất
    return sorted(h)  # trả k món lớn nhất
```

## Ví dụ

- Cây 7 nút, khoảng hẹp trúng 2 -> chỉ thăm đường cần thiết.
- Stream 100 số, k = 3 -> chỉ giữ 3 số lớn nhất.

| Bài | Đề | Ràng buộc |

| 1b | Phần tử nhỏ thứ k trong BST | $O(h + k)$ |
| 1c | Tổ tiên chung thấp nhất của 2 nút trong BST | $O(h)$ |
| 1d | Tổng các nút có giá trị trong `[lo, hi]` | Cắt nhánh ngoài khoảng |


### Bài 2: Heap

| Bài | Đề |
| --- | --- |
| 2a | Phần tử lớn thứ k trong mảng, $O(n \log k)$ |
| 2b | Gộp k danh sách liên kết đã sắp |
| 2c | Trung vị của luồng số: `addNum`, `findMedian` mỗi lần $O(\log n)$ bằng 2 heap |
| 2d | k từ xuất hiện nhiều nhất, hòa thì theo alphabet |

```text
2a: [3,2,1,5,6,4], k=2 -> 5
2c: add 1, add 2 -> 1.5; add 3 -> 2
```

### Bài 3: Kết hợp (nâng cao)

1. k điểm gần gốc tọa độ nhất trong $10^6$ điểm, $O(n \log k)$.
2. Lập lịch CPU: các task có thời điểm đến và thời gian chạy. Luôn chạy task ngắn nhất đang chờ. In thứ tự hoàn thành.
3. Iterator duyệt BST theo thứ tự, `next()` $O(1)$ trung bình, bộ nhớ $O(h)$.
