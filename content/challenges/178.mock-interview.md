## Giới thiệu

Bạn thi thử như phỏng vấn thật. Bấm giờ cắt ngang khi hết giờ.

## Kiến thức cần nhớ

### Vòng coding 40 phút

- 2 bài mảng chuỗi hoặc cây đồ thị.
- Nói to suy nghĩ và dry-run đầy đủ.
- Ví dụ đời thường: giống đá giao hữu đúng luật thi đấu.
- Chuyển bài đúng mốc 20 phút.

### Vòng design mini 30 phút

- Một hệ thống cache hoặc limiter.
- Vẽ sơ đồ hộp và ghi số liệu ước lượng.
- Ví dụ đời thường: giống vẽ nháp nhà trong 30 phút.
- Hỏi tải trước khi vẽ.

### Vòng kể chuyện và feedback

- Kể một chuyện refactor dưới 2 phút.
- Trả lời 3 câu chất vấn trade-off.
- Ví dụ đời thường: giống phản biện đồ án tốt nghiệp.
- Feedback gồm 2 điểm tốt, 2 điểm sửa, 1 việc làm ngay.

## Ví dụ

- 3 vòng đúng giờ, không vòng nào lố quá 3 phút -> đạt.
- Mỗi điểm rubric có hành vi cụ thể kèm theo -> đạt.

## 💻 Bài tập

Cần 1 bạn cùng luyện (hoặc tự ghi hình và tự chấm). Nộp vào `day-178/`.

### Bài 1: Ba vòng phỏng vấn thử

| Vòng | Thời gian | Nội dung |
| --- | --- | --- |
| Coding | 40 phút | 2 bài chưa gặp: 1 mảng/chuỗi, 1 cây/đồ thị. Chuyển bài ở phút 20. Nói to suy nghĩ, chạy tay 1 ví dụ trước khi chạy code |
| Design mini | 30 phút | Thiết kế cache phân tán hoặc rate limiter. Hỏi yêu cầu và tải trước khi vẽ |
| Hành vi | 20 phút | Kể 1 chuyện refactor dưới 2 phút, trả lời 3 câu chất vấn đánh đổi |

Ghi hình hoặc ghi âm cả 3 vòng.

### Bài 2: Rubric chấm

Người chấm dùng rubric 1-4 cho mỗi mục, mỗi điểm kèm **hành vi cụ thể** quan sát được:

| Mục | Điểm | Hành vi quan sát |
| --- | --- | --- |
| Làm rõ đề | | Ví dụ: "hỏi về input rỗng ở phút 2" |
| Chọn cách giải và độ phức tạp | | |
| Code đúng và sạch | | |
| Kiểm tra và ca biên | | |
| Giao tiếp | | |
| Quản lý thời gian | | |

Feedback cuối: 2 điểm tốt, 2 điểm cần sửa, 1 việc làm ngay.

### Bài 3: Đổi vai và cải thiện (nâng cao)

1. Đổi vai: bạn làm người phỏng vấn cho người kia. Ghi lại bạn học được gì khi ngồi ghế người chấm.
2. Xem lại bản ghi của mình. Ghi 3 thói quen xấu (ví dụ im lặng quá 1 phút, nhảy vào code ngay).
3. Làm lại 1 bài coding sau khi sửa "1 việc làm ngay". So thời gian và điểm.

### ✅ Tiêu chí hoàn thành

- [ ] 3 vòng đúng giờ, không vòng nào lố quá 3 phút.
- [ ] Rubric có hành vi cụ thể cho mọi mục.
- [ ] Có feedback 2-2-1 và bản ghi.
- [ ] Làm lại 1 bài và so kết quả.

## ❓ Câu hỏi ôn tập

2. Design mini vẽ gì?
3. Feedback theo mẫu nào?
4. Vì sao phải ghi âm?
