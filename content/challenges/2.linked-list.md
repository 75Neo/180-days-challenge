## Giới thiệu

Trong bài này, bạn sẽ làm quen với **nút** và **con trỏ**, học cách phân biệt hai loại linked list, và biết khi nào nên chọn linked list thay vì mảng.

## Kiến thức cần nhớ

### Nút và list đơn

- Mỗi nút gồm hai phần: dữ liệu và một con trỏ `next`.
- `next` trỏ tới nút kế tiếp trong chuỗi.
- `head` là nút đầu tiên. Đây là cửa vào duy nhất của list.
- Ví dụ đời thường: một đoàn tàu, mỗi toa chỉ biết toa đứng ngay sau nó.
- Muốn đọc phần tử thứ k, bạn phải bắt đầu từ `head` rồi đi qua từng nút.

### List đôi và list vòng

- List đôi có thêm con trỏ `prev`, trỏ ngược về nút đứng trước.
- Nhờ `prev`, bạn duyệt được cả hai chiều, và xóa một nút cũng nhanh hơn.
- List vòng là list mà nút cuối trỏ ngược về `head`.
- Ví dụ đời thường: lịch sử trình duyệt, bạn có thể đi tới và đi lui.
- Cái giá phải trả là tốn thêm bộ nhớ cho các con trỏ.

### So sánh với mảng

- Mảng truy cập phần tử thứ k trong $O(1)$.
- List chèn hoặc xóa ở đầu trong $O(1)$.
- Mảng thân thiện với cache hơn list, vì các phần tử nằm liền nhau trong bộ nhớ.
- Ví dụ đời thường: mảng giống kệ sách đánh số.

| Thao tác | Mảng | List đơn |
| --- | --- | --- |
| Đọc phần tử thứ k | $O(1)$ | $O(n)$ |
| Chèn hoặc xóa ở đầu | $O(n)$ | $O(1)$ |
| Chèn ở cuối | $O(1)$ | $O(n)$ nếu không có `tail` |
| Bộ nhớ thêm | Thấp | 1 con trỏ mỗi nút |

## Ví dụ

- Đầu vào: A -> B -> C, chèn X sau A. Kết quả: A -> X -> B -> C.
- Giải thích: chỉ cần nối lại hai con trỏ, nên không nút nào bị mất.

```python
# Chèn sau nút đã biết
new_node.next = cur.next  # nút mới trỏ tới nút kế
cur.next = new_node  # nút hiện tại trỏ sang nút mới
```

## 💻 Bài tập

Bạn viết bằng **C**, hoặc C++ nhưng không dùng `std::list`. Nộp code vào thư mục `day-002/`.

### Bài 1: Singly linked list

```c
typedef struct Node { int val; struct Node *next; } Node;
typedef struct { Node *head; Node *tail; size_t size; } SList;
```

Hãy cài đặt các hàm sau. Cột cuối cho biết độ phức tạp mong muốn của từng hàm.

| Hàm | Việc cần làm | Độ phức tạp |
| --- | --- | --- |
| `void sl_init(SList *l)` | Tạo list rỗng: `head = tail = NULL`, `size = 0` | $O(1)$ |
| `bool sl_push_front(SList *l, int x)` | Thêm vào đầu | $O(1)$ |
| `bool sl_push_back(SList *l, int x)` | Thêm vào cuối, nhờ con trỏ `tail` | $O(1)$ |
| `bool sl_pop_front(SList *l, int *out)` | Gỡ nút đầu. Nếu list rỗng thì trả `false` | $O(1)$ |
| `bool sl_insert_after(SList *l, Node *n, int x)` | Chèn một nút mới sau nút `n` | $O(1)$ |
| `bool sl_remove(SList *l, int x)` | Xóa nút đầu tiên có giá trị `x` | $O(n)$ |
| `Node *sl_find(const SList *l, int x)` | Trả về nút đầu tiên có giá trị `x`. Không thấy thì trả `NULL` | $O(n)$ |
| `bool sl_get(const SList *l, size_t k, int *out)` | Đọc phần tử thứ `k` | $O(k)$ |
| `void sl_reverse(SList *l)` | Đảo ngược list ngay tại chỗ, không cấp phát thêm nút nào | $O(n)$ |
| `void sl_clear(SList *l)` | Giải phóng toàn bộ nút | $O(n)$ |

**Ràng buộc**

- `tail` phải luôn đúng sau mọi thao tác, kể cả khi list có 0 hoặc 1 nút.
- Viết thêm hàm `void sl_print(const SList *l)` để in list dưới dạng `[1 -> 2 -> 3]`, giúp bạn debug dễ hơn.

**Test mẫu**

```text
push_back 1, 2, 3                 -> [1 -> 2 -> 3], size=3
insert_after(find(1), 9)          -> [1 -> 9 -> 2 -> 3]
remove(3)                         -> [1 -> 9 -> 2], tail->val = 2
reverse                           -> [2 -> 9 -> 1], tail->val = 1
pop_front x3, pop_front lần 4     -> lần 4 trả false, head = tail = NULL
push_back 5 sau khi rỗng          -> [5], head == tail
```

### Bài 2: Doubly linked list và lịch sử trình duyệt

Viết `DList`, trong đó mỗi nút có cả `prev` lẫn `next`. Ngoài ra, hãy cài thêm `dl_remove_node(DList *l, DNode *n)` với độ phức tạp $O(1)$.

Sau đó, dùng `DList` để làm lịch sử trình duyệt, với ba hành vi sau:

| Hàm | Hành vi |
| --- | --- |
| `visit(url)` | Xóa toàn bộ trang nằm sau trang hiện tại, thêm `url` vào cuối, rồi chuyển tới `url` |
| `back(steps)` | Lùi tối đa `steps` bước, rồi trả về URL hiện tại |
| `forward(steps)` | Tiến tối đa `steps` bước, rồi trả về URL hiện tại |

```text
visit a, b, c           -> hiện tại c
back(2)                 -> a
forward(1)              -> b
visit d                 -> d (trang c bị xóa)
forward(1)              -> d (không còn trang sau)
back(10)                -> a
```

### Bài 3: Đo mảng và list (nâng cao)

Dùng Dynamic Array từ ngày 1 và `SList` ở Bài 1. Với $n = 10^5$, hãy đo thời gian của ba việc sau:

1. `push_back` $n$ phần tử.
2. Chèn $n$ phần tử vào đầu.
3. Duyệt và tính tổng $n$ phần tử.

In bảng thời gian (đơn vị ms). Sau đó viết 3 câu giải thích vì sao duyệt mảng nhanh hơn duyệt list, dù cả hai đều là $O(n)$.

::tip
Dùng `clock_gettime(CLOCK_MONOTONIC, ...)` để đo thời gian. Mỗi phép đo chạy 5 lần, rồi lấy trung vị.
::
