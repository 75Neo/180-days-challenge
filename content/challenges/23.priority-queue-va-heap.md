## Giới thiệu

Bài này học về hàng đợi ưu tiên, qua ví dụ theo dõi lỗi phần mềm. Bạn sẽ thấy cách lấy ra việc khẩn nhất trong thời gian $O(\log n)$.

## Kiến thức cần nhớ

### Bài toán ưu tiên

- Có nhiều việc, mỗi việc có độ khẩn khác nhau.
- Mỗi lần chỉ cần lấy ra việc khẩn nhất, không cần sắp xếp hết.
- Nếu giữ danh sách luôn được sắp xếp thì việc chèn và sửa sẽ rất tốn kém.
- Ví dụ đời thường: phòng cấp cứu khám ca nặng trước.

### Hàng đợi ưu tiên và API

- Hàng đợi ưu tiên chỉ đảm bảo một điều: phần tử lấy ra luôn là phần tử khẩn nhất.
- API gồm: chèn, lấy phần tử khẩn nhất, nhìn phần tử khẩn nhất, và đổi độ ưu tiên.
- Bạn có thể dùng nó như một hộp đen, không cần biết bên trong là gì.
- Ví dụ đời thường: bốc số thứ tự ưu tiên.

### Min-heap, max-heap, và cách lưu bằng mảng

- Max-heap đặt phần tử lớn nhất ở gốc.
- Min-heap đặt phần tử nhỏ nhất ở gốc.
- Cây hoàn chỉnh có thể nhét vừa khít vào một mảng.
- Ví dụ đời thường: sếp to nhất ngồi ở đỉnh tháp.
- Với nút ở vị trí `i`: cha ở `(i-1)//2`, con trái ở `2i+1`, con phải ở `2i+2`.

| Thao tác | List xếp sẵn | Heap |
| --- | --- | --- |
| Chèn | $O(n)$ | $O(\log n)$ |
| Lấy khẩn nhất | $O(1)$ | $O(\log n)$ |
| Đổi ưu tiên | $O(n)$ | $O(\log n)$ |

## Ví dụ

- Đầu vào: chèn các lỗi có độ ưu tiên 5, 9, 7 vào max-heap. Kết quả: gốc là 9.
- Giải thích: trên mọi đường đi từ gốc xuống, cha luôn khẩn hơn con.

## 💻 Bài tập

Ngôn ngữ: **C++**. Không được dùng `std::priority_queue` hay `std::make_heap`. Nộp vào thư mục `day-023/`.

### Bài 1: Max-heap trên mảng

```cpp
class MaxHeap {
 public:
  void push(int x);
  int  top() const;          // ném std::out_of_range nếu rỗng
  int  pop();                // lấy và trả gốc
  size_t size() const; bool empty() const;
  bool isValid() const;      // kiểm tra bất biến heap, dùng khi test
 private:
  std::vector<int> a;
  static size_t parent(size_t i) { return (i - 1) / 2; }
  static size_t left(size_t i)   { return 2 * i + 1; }
  static size_t right(size_t i)  { return 2 * i + 2; }
};
```

| Thao tác | Độ phức tạp |
| --- | --- |
| `push`, `pop` | $O(\log n)$ |
| `top`, `size` | $O(1)$ |

```text
push 5, 9, 7          -> top = 9, mảng [9, 5, 7]
push 1, 12            -> top = 12
pop x5                -> 12, 9, 7, 5, 1
pop khi rỗng          -> ném out_of_range
```

### Bài 2: Hàng đợi ưu tiên cho ticket hỗ trợ

`struct Ticket { int priority; long long createdAt; std::string title; };`

Viết `TicketQueue` dựa trên heap, với comparator như sau: ticket có ưu tiên cao hơn sẽ ra trước. Nếu hai ticket cùng ưu tiên, ticket được tạo sớm hơn sẽ ra trước.

```text
push (3, t=1, "A"), (5, t=2, "B"), (3, t=0, "C"), (5, t=3, "D")
pop hết -> B, D, C, A
```

Hãy chuyển `MaxHeap` thành template `Heap<T, Compare>` để dùng chung cho cả hai bài.

### Bài 3: So sánh 3 cách cài (nâng cao)

Cài hàng đợi ưu tiên theo ba cách: (a) mảng chưa sắp xếp, (b) mảng luôn được sắp xếp, và (c) heap.

Chạy kịch bản với $n = 10^5$: cứ 2 lần `push` một số ngẫu nhiên thì xen thêm 1 lần `pop`. In bảng thời gian, cùng độ phức tạp lý thuyết của từng thao tác.

```text
impl         push     pop      tổng (ms)
unsorted     O(1)     O(n)     ...
sorted       O(n)     O(1)     ...
heap         O(logn)  O(logn)  ...
```
