## Giới thiệu

Bài này học về disjoint set (tập rời nhau), dùng để gom nhóm và trả lời câu hỏi "hai người có cùng nhóm không". Cấu trúc này giúp gộp cộng đồng nhanh và gọn.

## Kiến thức cần nhớ

### Bài toán gom nhóm

- Mỗi phần tử thuộc đúng một nhóm tại mỗi thời điểm.
- Cần hỏi hai người có cùng nhóm hay không.
- Cần gộp hai nhóm thành một khi hai người kết bạn.
- Ví dụ đời thường: gộp hai nhóm chat thành một nhóm.

### API ba thao tác

- `makeSet(x)`: tạo một nhóm riêng chỉ chứa `x`.
- `find(x)`: trả về đại diện của nhóm chứa `x`.
- `union(a, b)`: gộp nhóm của `a` và nhóm của `b`.
- Ví dụ đời thường: kiểm tra hai bạn có cùng lớp không, rồi chuyển hai bạn về chung một lớp.

### Cài đặt ngây thơ

- Mỗi phần tử lưu trực tiếp id nhóm của mình trong một dict.
- `find` chỉ việc đọc dict nên rất nhanh, $O(1)$.
- `union` phải duyệt và viết lại id của cả nhóm, nên tốn $O(n)$.
- Ví dụ đời thường: đổi tên lớp thì phải sửa thẻ của từng học sinh.

```python
# Cài đặt ngây thơ: find nhanh, union chậm
parent = {}  # mỗi người -> id nhóm
def find(x):
    return parent[x]  # đọc trực tiếp
def union(a, b):
    ida, idb = parent[a], parent[b]  # lấy 2 id
    if ida == idb: return False  # đã cùng nhóm
    for k in parent:  # duyệt hết để viết lại
        if parent[k] == idb:
            parent[k] = ida
    return True
```

## Ví dụ

- Đầu vào: 5 người riêng lẻ, hỏi 1 và 2 có cùng nhóm không. Kết quả: khác nhóm.
- Điều này cho thấy lúc đầu ai cũng đứng một mình.
- Đầu vào: `union(1,2)`, rồi hỏi 1 và 2. Kết quả: cùng nhóm, trả về True.
- Điều này cho thấy sau khi gộp, hai người đã thuộc cùng một nhóm.

## 💻 Bài tập

Ngôn ngữ: **C++**. Nộp vào thư mục `day-032/`. Phần tử là số nguyên trong khoảng `0..n-1`.

### Bài 1: Disjoint set ngây thơ (quick-find)

```cpp
class QuickFind {
 public:
  explicit QuickFind(int n);           // makeSet cho 0..n-1
  int  find(int x) const;              // O(1)
  bool unite(int a, int b);            // O(n), trả false nếu đã cùng nhóm
  bool connected(int a, int b) const;
  int  count() const;                  // số nhóm hiện tại
};
```

```text
n=5                           -> count = 5, connected(1,2) = false
unite(1,2); unite(3,4)        -> count = 3
unite(2,1)                    -> false (đã cùng nhóm)
unite(1,4)                    -> connected(2,3) = true, count = 2
find(9)                       -> ném out_of_range
```

### Bài 2: Quick-union không tối ưu

Viết `QuickUnion` lưu một mảng `parent`. Hàm `find` đi lên đến gốc. Hàm `unite` nối gốc của `a` vào gốc của `b`.

Hãy tạo một dãy thao tác xấu: `unite(0,1), unite(1,2), ..., unite(n-2, n-1)`, rồi gọi `find(0)`. Đếm số bước mà `find` phải đi, và in ra độ cao của cây.

### Bài 3: Bài toán mạng bạn bè (nâng cao)

Đọc file `friends.txt`, mỗi dòng có dạng `a b` thể hiện quan hệ bạn bè:

1. In số nhóm bạn bè (số thành phần liên thông).
2. In kích thước của nhóm lớn nhất.
3. Trả lời truy vấn `a b`: hai người có cùng nhóm không?
4. Sinh $n = 10^4$ người và $10^4$ cạnh ngẫu nhiên. Đo thời gian của `QuickFind` và `QuickUnion`. Ghi lại kết quả để so với bản tối ưu ở ngày 33.

```text

-> 3 nhóm với n=6 ({0,1,2}, {3,4}, {5}), nhóm lớn nhất 3
```
