# 📔 Day 32: Disjoint set: bài toán distinct subsets và cài đặt naive

## Giới thiệu
Bài này học disjoint set để gom nhóm và hỏi cùng nhóm.
Cấu trúc này giúp gộp cộng đồng nhanh và gọn.

## Kiến thức cần nhớ

### Bài toán gom nhóm
- Mỗi phần tử thuộc đúng một nhóm tại mỗi thời điểm.
- Cần hỏi hai người có cùng nhóm không.
- Cần gộp hai nhóm thành một khi kết bạn.
- Ví dụ đời thường: gộp hai nhóm chat thành một nhóm.

### API ba thao tác
- `makeSet(x)`: tạo nhóm riêng chỉ chứa x.
- `find(x)`: trả về đại diện nhóm của x.
- `union(a, b)`: gộp nhóm của a và b.
- Ví dụ đời thường: hỏi cùng lớp, rồi chuyển hai bạn về chung lớp.

### Cài đặt ngây thơ
- Mỗi phần tử lưu trực tiếp id nhóm trong dict.
- `find` chỉ đọc dict nên rất nhanh $O(1)$.
- `union` phải duyệt viết lại id cả nhóm nên $O(n)$.
- Ví dụ đời thường: đổi tên lớp phải sửa thẻ từng học sinh.

```python
# Cài đặt ngây thơ: find nhanh, union chậm
parent = {}  # mỗi người -> id nhóm
def find(x):
    return parent[x]  # đọc trực tiếp
def union(a, b):
    ida, idb = parent[a], parent[b]  # lấy 2 id
    if ida == idb: return False  # đã cùng nhóm
    for k in parent:  # duyệt hết để viết lại
        if parent[k] == idb:
            parent[k] = ida
    return True
```

## Ví dụ
- Input: 5 người riêng lẻ, hỏi 1 và 2 -> Output: khác nhóm.
- Câu này cho thấy lúc đầu ai cũng một mình.
- Input: `union(1,2)` rồi hỏi 1 và 2 -> Output: cùng nhóm, trả True.
- Câu này cho thấy gộp xong thì hỏi ra cùng nhóm.

## 💻 Bài tập
1. Cho 5 người và 3 lượt kết bạn, liệt kê nhóm cuối và trả lời 2 truy vấn.
Kiểm tra: nhóm đúng, câu trả lời cùng/khác nhóm đúng.
2. Đếm số lần viết lại id ở mỗi lần gộp trong bài trên.
Kiểm tra: ghi đúng số lần mỗi bước và tổng cộng.
3. Cho n phần tử, gộp vụng về luôn nhập nhóm lớn vào nhóm nhỏ.
Kiểm tra: tính đúng tổng lần viết lại và độ phức tạp $O(n^2)$.
4. Cho lưới ảnh nhỏ 3x3, ô kề cùng màu thì gộp.
Kiểm tra: đếm đúng số vùng màu cuối cùng.
