## Giới thiệu

Bài này học Union-Find nhanh hơn nhờ biểu diễn bằng cây và hai mẹo tối ưu. Sau đó, bạn dùng nó để tìm đường nối rẻ nhất giữa các điểm bằng thuật toán Kruskal.

## Kiến thức cần nhớ

### Từ danh sách sang cây

- Mỗi nhóm là một cây, và gốc của cây là đại diện của nhóm.
- Mỗi nút chỉ cần giữ con trỏ tới cha của nó.
- `union` chỉ việc nối gốc này vào gốc kia.
- Ví dụ đời thường: sáp nhập lớp chỉ cần đổi biển lớp trưởng.

### Nén đường đi và hợp theo hạng

- Nén đường đi: khi `find`, nối thẳng mọi nút trên đường về gốc.
- Hợp theo hạng: cây nhỏ hơn sẽ nằm dưới gốc của cây lớn hơn.
- Mỗi gốc giữ một con số "hạng" để so sánh lớn nhỏ.
- Ví dụ đời thường: đường tắt mới mở thì lần sau đi sẽ nhanh hơn.

```python
# Union-Find có nén đường đi + hợp theo hạng
cha = {}  # nút -> cha
hang = {}  # gốc -> hạng
def find(x):
    if cha[x] != x:  # chưa tới gốc
        cha[x] = find(cha[x])  # nối thẳng về gốc
    return cha[x]
def union(a, b):
    ra, rb = find(a), find(b)  # tìm 2 gốc
    if ra == rb: return False  # đã cùng nhóm
    if hang[ra] < hang[rb]:  # cây nhỏ chui dưới
        ra, rb = rb, ra
    cha[rb] = ra  # nối gốc nhỏ vào gốc lớn
    if hang[ra] == hang[rb]:  # bằng hạng thì gốc mới cao thêm 1
        hang[ra] += 1
    return True
```

### Thuật toán Kruskal

- Sắp xếp mọi cạnh theo trọng số tăng dần.
- Duyệt từng cạnh. Nếu hai đầu cạnh chưa cùng nhóm thì nhận cạnh và gộp nhóm.
- Nếu hai đầu cạnh đã cùng nhóm thì bỏ qua, để tránh tạo chu trình.
- Ví dụ đời thường: nối các trạm điện bằng ít dây nhất có thể.

| Tiêu chí | Ngây thơ | Cây + 2 mẹo |
|---|---|---|
| Tìm | $O(1)$ | Gần $O(1)$ |
| Gộp | $O(n)$ vì viết lại | Gần $O(1)$ nhờ nối gốc |
| Dãy thao tác dài | Phình tới $O(n^2)$ | Gần tuyến tính |

## Ví dụ

- Đầu vào: tam giác với các cạnh 1, 2, 3. Kết quả: nhận cạnh 1 và cạnh 2, tổng là 3.
- Điều này cho thấy cạnh 3 bị loại vì sẽ tạo thành vòng tròn.
- Đầu vào: gọi `find` hai lần trên một nhánh sâu. Kết quả: lần thứ hai chỉ đi 1 bước.
- Điều này cho thấy việc nén đường đi đã phát huy tác dụng.

### Bài 1: Union-Find tối ưu

```cpp
class DSU {
 public:
  explicit DSU(int n);
  int  find(int x);          // nén đường đi
  bool unite(int a, int b);  // hợp theo rank, bằng rank thì gốc mới tăng rank 1
  int  size(int x);          // kích thước nhóm chứa x
  int  count() const;
};
```

Viết thêm một bản `find` **dùng vòng lặp** (không đệ quy), áp dụng kỹ thuật chia đôi đường đi (`parent[x] = parent[parent[x]]`).

```text
Dãy xấu ngày 32 với n = 10^6 -> find(0) chạy tức thì, không tràn stack
unite(0,1); unite(2,3); unite(0,3) -> size(1) = 4
```
