## Giới thiệu

Bài này học Union-Find nhanh bằng cây và hai mẹo nén.
Mẹo này giúp Kruskal tìm đường nối rẻ nhất.

## Kiến thức cần nhớ

### Từ danh sách sang cây

- Mỗi nhóm là một cây, gốc cây là đại diện.
- Mỗi nút chỉ giữ con trỏ tới cha của nó.
- `union` chỉ nối gốc này sang gốc kia.
- Ví dụ đời thường: sáp nhập lớp chỉ cần đổi biển lớp trưởng.

### Nén đường đi và hợp theo hạng

- Nén đường đi: lúc `find` thì nối thẳng mọi nút về gốc.
- Hợp theo hạng: cây nhỏ chui dưới gốc cây lớn.
- Mỗi gốc giữ con số hạng để so lớn nhỏ.
- Ví dụ đời thường: đường tắt mới mở thì lần sau đi nhanh.

```python
# Union-Find có nén đường đi + hợp theo hạng
cha = {}  # nút -> cha
hang = {}  # gốc -> hạng
def find(x):
    if cha[x] != x:  # chưa tới gốc
        cha[x] = find(cha[x])  # nối thẳng về gốc
    return cha[x]
def union(a, b):
    ra, rb = find(a), find(b)  # tìm 2 gốc
    if ra == rb: return False  # đã cùng nhóm
    if hang[ra] < hang[rb]:  # cây nhỏ chui dưới
        ra, rb = rb, ra
    cha[rb] = ra  # nối gốc nhỏ vào gốc lớn
    if hang[ra] == hang[rb]:  # bằng hạng thì gốc mới cao thêm 1
        hang[ra] += 1
    return True
```

### Thuật toán Kruskal

- Sắp xếp mọi cạnh theo trọng số tăng dần.
- Duyệt từng cạnh, chưa cùng nhóm thì nhận và gộp.
- Cùng nhóm rồi thì bỏ qua để tránh chu trình.
- Ví dụ đời thường: nối các trạm điện bằng ít dây nhất.

| Tiêu chí | Ngây thơ | Cây + 2 mẹo |
|---|---|---|
| Tìm | $O(1)$ | Gần $O(1)$ |
| Gộp | $O(n)$ viết lại | Gần $O(1)$ nối gốc |
| Dãy dài | Phình $O(n^2)$ | Gần tuyến tính |

## Ví dụ

- Input: tam giác cạnh 1, 2, 3 -> Output: nhận cạnh 1 và 2, tổng 3.
- Câu này cho thấy cạnh 3 bị loại vì tạo vòng tròn.
- Input: `find` hai lần trên nhánh sâu -> Output: lần 2 chỉ 1 bước.
- Câu này cho thấy nén đường đi phát huy tác dụng.

### Bài 1: Union-Find tối ưu

```cpp
class DSU {
 public:
  explicit DSU(int n);
  int  find(int x);          // nén đường đi
  bool unite(int a, int b);  // hợp theo rank, bằng rank thì gốc mới tăng rank 1
  int  size(int x);          // kích thước nhóm chứa x
  int  count() const;
};
```

Viết thêm `find` bản **vòng lặp** (không đệ quy) dùng kỹ thuật chia đôi đường đi (`parent[x] = parent[parent[x]]`).

```text
Dãy xấu ngày 32 với n = 10^6 -> find(0) chạy tức thì, không tràn stack
unite(0,1); unite(2,3); unite(0,3) -> size(1) = 4
```
