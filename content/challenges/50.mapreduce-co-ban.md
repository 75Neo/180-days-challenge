## Giới thiệu

Bài này học MapReduce chia việc lớn cho nhiều máy.
Mô hình này giúp đếm triệu phiếu bầu siêu nhanh.

## Kiến thức cần nhớ

### Song song và phân tán

- Song song: nhiều luồng chung một bộ nhớ một máy.
- Phân tán: nhiều máy riêng bộ nhớ, nói nhau qua mạng.
- Phân tán lo thêm máy chết giữa chừng và mạng chậm.
- Ví dụ đời thường: một bếp nhiều tay so với nhiều bếp nhiều quán.

### Chuyện vịt Donald

- Donald một mình đếm triệu phiếu tới già không xong.
- Thuê đàn vịt con mỗi con đếm một thùng riêng.
- Mỗi con báo cáo số phiếu từng ứng viên thùng mình.
- Ví dụ đời thường: chia lớp chấm thi rồi cộng bảng điểm lại.

### Map rồi reduce

- Map: nhận một mảnh, nhả ra cặp khóa-giá trị trung gian.
- Shuffle: gom mọi giá trị cùng khóa về cùng một máy.
- Reduce: gộp danh sách giá trị thành kết quả cuối.
- Ví dụ đời thường: đếm từ thì map nhả (từ,1), reduce cộng lại.

```python
# Đếm từ bằng map-reduce thu nhỏ
def map_dong(dong):
    return [(tu, 1) for tu in dong.split()]  # mỗi từ một phiếu
def reduce_tu(tu, ds):
    return (tu, sum(ds))  # cộng hết phiếu cùng từ
```

## Ví dụ

- Input: 3 dòng văn bản đếm từ -> Output: tổng đếm bằng tổng số từ vào.
- Câu này kiểm tra không mất không thừa một từ.
- Input: đầu vào rỗng -> Output: đầu ra rỗng, không treo.
- Câu này kiểm tra biên rỗng xử lý sạch.

### Bài 1: Khung MapReduce tí hon

```python
def run_mapreduce(inputs: list, mapper, reducer, n_workers: int = 4, combiner=None) -> dict:
    """mapper(item) -> iterable[(key, value)]
       reducer(key, values: list) -> value
       Map song song bằng multiprocessing.Pool, shuffle gom theo key, reduce song song."""
```

| Giai đoạn | Yêu cầu |
| --- | --- |
| Map | Chia `inputs` thành `n_workers` phần |
| Shuffle | Gom `dict[key, list[value]]`, phân key cho reducer bằng `hash(key) % n_workers` |
| Reduce | Chạy song song theo phân vùng |
| Combiner | Nếu có, gộp cục bộ sau Map trước Shuffle |

