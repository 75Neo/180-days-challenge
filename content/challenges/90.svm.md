## Giới thiệu

Bài này học SVM tìm biên lề rộng nhất. Bạn dùng nó cho dữ liệu phi tuyến như vòng tròn lồng nhau.

## Kiến thức cần nhớ

### Lề và vector hỗ trợ

- Lề là khoảng cách từ biên tới điểm gần nhất mỗi lớp.
- SVM cực đại hóa lề vì lề rộng khó bị nhiễu đẩy qua.
- Điểm nằm đúng biên lề gọi là vector hỗ trợ.
- Xóa điểm thường biên không đổi, xóa hỗ trợ biên xoay ngay.

### Lề mềm và C

- Dữ liệu thật hiếm khi tách sạch nên cho phép vài điểm vi phạm.
- C lớn phạt nặng nên lề hẹp mà ít sai huấn luyện.
- C nhỏ chấp nhận sai để lề rộng tổng quát tốt.
- C là núm chỉnh chính, phải dò bằng kiểm định chéo.

### Ánh xạ và kernel

- Vòng tròn lồng nhau không đường thẳng nào tách được.
- Thêm chiều bình phương bán kính thì tách phẳng đẹp.
- Kernel tính tích vô hướng ở không gian mới mà không dựng nó.
- Tuyến tính cho dữ liệu thẳng, đa thức cho cong vừa, RBF cho cong tùy ý.

| Kernel | Khi nào dùng |
|---|---|
| Tuyến tính | Dữ liệu đã tách thẳng |
| Đa thức | Biên cong vừa |
| RBF | Vòng tròn lồng nhau |

### Gamma và khi nào thắng

- Gamma lớn biên uốn sát dữ liệu dễ thuộc lòng.
- Gamma nhỏ biên mượt có thể học thiếu.
- Phải dò lưới C và gamma vì chúng tương tác nhau.
- SVM thắng ở chiều cao mẫu vừa, thua ở dữ liệu khổng lồ vì huấn luyện nặng.

## Ví dụ

- Input: 6 điểm tách được, vẽ biên lề cực đại. Output: vài điểm biên là hỗ trợ.
- Giải thích: chỉ điểm sát biên mới quyết định vị trí biên.
- Input: RBF với gamma tiến về 0. Output: biên gần phẳng như tuyến tính.
- Giải thích: mỗi điểm ảnh hưởng rộng nên biên mượt ra.

## 💻 Bài tập

Ngôn ngữ: **Python 3** với NumPy. Bài 3 dùng `sklearn.svm`. Nộp vào `day-090/`.

### Bài 1: Linear SVM bằng subgradient

```python
class LinearSVM:
    def __init__(self, C: float = 1.0, lr: float = 1e-3, epochs: int = 1000, seed: int = 0): ...
    def fit(self, X, y): ...           # y trong {-1, +1}
    def decision_function(self, X): ...
    def predict(self, X): ...
    def support_vectors(self, X, y, tol=1e-3): ...   # điểm có y * f(x) <= 1 + tol
```

Mục tiêu (hinge loss): $\min_{w,b} \frac{1}{2}\lVert w \rVert^2 + C \sum_i \max(0, 1 - y_i(w \cdot x_i + b))$.

```text
2 cụm tách được, C lớn  -> accuracy train 100%, lề = 2 / ||w||
Xóa 1 điểm không phải vector hỗ trợ rồi huấn luyện lại -> biên gần như không đổi
Xóa 1 vector hỗ trợ     -> biên dịch chuyển (in w, b trước và sau)
```

Vẽ biên, 2 đường lề, và khoanh các vector hỗ trợ.

### Bài 2: Ảnh hưởng của C

Dữ liệu 2 lớp có chồng lấn. Chạy `C = 0.01, 0.1, 1, 10, 100`.

```text
C       độ_rộng_lề    số_vector_hỗ_trợ    acc_train    acc_test
0.01    ...
100     ...
```

Chọn `C` bằng 5-fold cross-validation (dùng hàm ngày 56).

### Bài 3: Kernel (nâng cao)

1. Dữ liệu 2 vòng tròn đồng tâm. Linear SVM thất bại.
2. Thêm đặc trưng thủ công $x_3 = x_1^2 + x_2^2$. Linear SVM trên 3 chiều tách được. Vẽ minh họa 3D.
3. Dùng `sklearn.svm.SVC(kernel="rbf")` với `gamma = 0.1, 1, 10, 100`. Vẽ 4 biên quyết định. Chỉ ra gamma nào học thuộc.
4. Tự cài hàm kernel RBF và kiểm tra ma trận Gram bằng với `sklearn.metrics.pairwise.rbf_kernel`.
