## Giới thiệu

Bài này học về hàm mất mát (loss), lan truyền ngược (backpropagation) và các hàm kích hoạt. Bạn sẽ dùng những kiến thức này để huấn luyện một mạng noron thực sự chạy được.

## Kiến thức cần nhớ

### Loss và gradient descent

- Định nghĩa: loss đo khoảng cách giữa dự đoán và nhãn đúng.
- Mục tiêu khi học là tìm các trọng số làm loss nhỏ nhất.
- Ví dụ đời thường: như đo độ lệch của phát bắn so với hồng tâm.
- Gradient descent: đi ngược hướng dốc để xuống đáy.
- Tốc độ học quá lớn thì sẽ nhảy qua đáy, quá nhỏ thì bò rất chậm.

### Lan truyền ngược

- Định nghĩa: chia lỗi ở đầu ra ngược trở về từng noron.
- Noron nào góp nhiều lỗi thì được điều chỉnh nhiều hơn.
- Ví dụ đời thường: như truy trách nhiệm từ cuối dây chuyền.
- Gồm 2 pha: lan truyền xuôi để tính dự đoán, và lan truyền ngược để điều chỉnh.
- Dùng quy tắc dây chuyền để tính đạo hàm cho từng tầng.

| Hàm kích hoạt | Dạng | Khi nào dùng |
|---|---|---|
| Sigmoid | Cong từ 0 đến 1 | Đầu ra nhị phân |
| ReLU | Giữ giá trị dương, cắt phần âm | Tầng ẩn, mặc định |
| Softmax | Biến thành xác suất | Phân loại nhiều lớp |
| Tanh | Từ -1 đến 1 | Dữ liệu quanh 0 |

### Siêu tham số

- Định nghĩa: các giá trị do người dùng chọn, mạng không tự học ra.
- Gồm tốc độ học, số epoch, cỡ batch.
- Ví dụ đời thường: như núm vặn của bếp, do đầu bếp chỉnh.
- Chọn sai siêu tham số thì mạng giỏi cũng học hỏng.
- Nên thử vài giá trị rồi đo trên tập kiểm tra.

### Thêm hàm kích hoạt

| Hàm | Dạng | Ghi chú |
| --- | --- | --- |
| Bậc thang (step) | 0 hoặc 1 | Dùng trong perceptron gốc, không có đạo hàm để lan ngược |
| Leaky ReLU | Giữ giá trị dương, phần âm nhân với hệ số nhỏ như 0.01 | Tránh việc noron "chết" khi luôn nhận đầu vào âm |

## Ví dụ

- Đầu vào: loss dao động lên xuống liên tục. Kết quả: nên giảm tốc độ học.
- Giải thích: bước quá lớn nên mô hình nhảy qua đáy liên tục.

```python
# Cập nhật 1 trọng số theo gradient
w = w - toc_do_hoc * dao_ham  # bước ngược dốc
print(w)  # trọng số mới
```

### Bài 1: Backprop cho MLP

```python
class MLP:
    def __init__(self, sizes: list[int], activation="relu", seed=0): ...
    def forward(self, X) -> np.ndarray: ...            # đầu ra softmax, lưu cache cho backward
    def backward(self, y_onehot) -> list[tuple]: ...   # trả (dW, db) mỗi tầng
    def step(self, grads, lr): ...
def cross_entropy(probs, y_onehot) -> float: ...
```

**Kiểm tra gradient** là bắt buộc: với mạng nhỏ `[4, 5, 3]`, so sánh `dW` tính bằng backprop với sai phân trung tâm $\frac{L(w+h) - L(w-h)}{2h}$, với $h = 10^{-5}$. Sai số tương đối phải dưới `1e-6`.

```text

gradient check -> relative error < 1e-6 cho mọi tầng
```
