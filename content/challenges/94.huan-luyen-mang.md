## Giới thiệu

Bài này học loss, lan truyền ngược và hàm kích hoạt.
Dùng để huấn luyện mạng noron chạy được thật.

## Kiến thức cần nhớ

### Loss và gradient descent

- Định nghĩa: loss đo khoảng cách giữa đoán và nhãn đúng.
- Mục tiêu học là tìm trọng số làm loss nhỏ nhất.
- Ví dụ đời thường: như đo độ lệch bia bắn khỏi hồng tâm.
- Gradient descent: bước ngược hướng dốc để xuống đáy.
- Tốc độ học lớn thì vọt qua đáy, bé thì bò chậm.

### Lan truyền ngược

- Định nghĩa: chia lỗi đầu ra ngược về từng noron.
- Noron góp lỗi nhiều thì chỉnh nhiều hơn.
- Ví dụ đời thường: như truy trách nhiệm từ cuối dây chuyền.
- Gồm 2 pha: lan xuôi tính đoán, lan ngược chỉnh.
- Dùng quy tắc dây chuyền để tính đạo hàm từng lớp.

| Hàm kích hoạt | Dạng | Khi nào dùng |
|---|---|---|
| Sigmoid | Cong 0 tới 1 | Đầu ra nhị phân |
| ReLU | Giữ dương, cắt âm | Tầng ẩn mặc định |
| Softmax | Thành xác suất | Phân loại nhiều lớp |
| Tanh | Từ -1 tới 1 | Dữ liệu quanh 0 |

### Siêu tham số

- Định nghĩa: số do người chọn, mạng không tự học.
- Gồm tốc độ học, số epoch, cỡ batch.
- Ví dụ đời thường: như núm vặn bếp do đầu bếp chỉnh.
- Sai siêu tham số thì mạng giỏi cũng học hỏng.
- Nên thử vài giá trị rồi đo trên tập kiểm tra.

### Thêm hàm kích hoạt

| Hàm | Dạng | Ghi chú |
| --- | --- | --- |
| Bậc thang (step) | 0 hoặc 1 | Dùng trong perceptron gốc, không có đạo hàm để lan ngược |
| Leaky ReLU | Giữ dương, âm nhân hệ số nhỏ như 0.01 | Tránh nơ-ron "chết" khi luôn nhận đầu vào âm |

## Ví dụ

- Input: loss dao động vọt lên xuống -> Output: giảm tốc độ học.
- Giải thích: bước quá lớn nên nhảy qua đáy liên tục.

```python
# Cập nhật 1 trọng số theo gradient
w = w - toc_do_hoc * dao_ham  # bước ngược dốc
print(w)  # trọng số mới
```

### Bài 1: Backprop cho MLP

```python
class MLP:
    def __init__(self, sizes: list[int], activation="relu", seed=0): ...
    def forward(self, X) -> np.ndarray: ...            # đầu ra softmax, lưu cache cho backward
    def backward(self, y_onehot) -> list[tuple]: ...   # trả (dW, db) mỗi tầng
    def step(self, grads, lr): ...
def cross_entropy(probs, y_onehot) -> float: ...
```

**Kiểm tra gradient** bắt buộc: với mạng nhỏ `[4, 5, 3]`, so `dW` từ backprop với sai phân trung tâm $\frac{L(w+h) - L(w-h)}{2h}$, $h = 10^{-5}$. Sai số tương đối dưới `1e-6`.

```text
Học XOR với [2, 4, 2], 2000 bước -> accuracy 100%
gradient check -> relative error < 1e-6 cho mọi tầng
```
