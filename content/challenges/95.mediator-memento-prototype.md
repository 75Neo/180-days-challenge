## Giới thiệu

Bài này học ba pattern: Mediator (trạm điều phối), Memento (lưu trạng thái để khôi phục) và Prototype (nhân bản từ mẫu). Chúng giúp giảm các dây nối chằng chịt giữa các đối tượng.

## Kiến thức cần nhớ

### Mediator

- Định nghĩa: một trạm trung tâm gom mọi giao tiếp giữa các đối tượng.
- Các đối tượng chỉ biết trạm, không biết nhau.
- Ví dụ đời thường: như tháp không lưu điều phối máy bay.
- Thêm một máy mới chỉ cần đăng ký với trạm.
- Tránh được việc số đường nối tăng theo bình phương.

### Memento

- Định nghĩa: chụp lại trạng thái để khôi phục sau này, mà không để lộ phần bên trong.
- Có 3 vai: nhân vật tự chụp trạng thái, vé lưu kín, và menu giữ vé.
- Ví dụ đời thường: như vé save game được cất trong két, không ai cần đọc nội dung.
- Menu chỉ cất vé, không được mở ra xem bên trong.
- Muốn quay lại thì lấy vé đưa cho nhân vật, để nhân vật tự khôi phục.

| Pattern | Vấn đề | Cách giải quyết |
|---|---|---|
| Mediator | Các đối tượng nối nhau chằng chịt | Giao tiếp qua một trạm |
| Memento | Muốn undo nhưng lộ phần bên trong | Chụp thành vé kín |
| Prototype | Tạo mới tốn kém | Nhân bản từ mẫu |

### Prototype

- Định nghĩa: tạo đối tượng mới bằng cách sao chép từ một mẫu có sẵn.
- Nhanh hơn việc dựng từ đầu khi khởi tạo tốn kém.
- Ví dụ đời thường: như photo một đơn mẫu thay vì viết lại từ đầu.
- Sao chép sâu (deep copy) thì các bản độc lập; sao chép nông (shallow copy) thì các bản chia sẻ chung phần ruột.
- Cần chú ý sao chép đúng toàn bộ phần có thể thay đổi.

## Ví dụ

- Đầu vào: 10 máy bay cần phối hợp với nhau. Kết quả: mỗi máy chỉ cần nối với 1 trạm.
- Giải thích: không còn các đường nối từng cặp với nhau nữa.

```python
# Sao chép mẫu thay vì dựng mới
import copy
quai_moi = copy.deepcopy(quai_mau)  # sao chép độc lập
print(quai_moi)  # dùng ngay
```

## 💻 Bài tập

Ngôn ngữ: **C++17** (hoặc Java). Nộp vào thư mục `day-095/`.

### Bài 1: Mediator cho tháp điều khiển

```cpp
struct Mediator { virtual void notify(Aircraft &sender, const std::string &event) = 0; virtual ~Mediator() = default; };
class ControlTower : public Mediator { /* giữ danh sách máy bay và trạng thái đường băng */ };
class Aircraft {
 public:
  Aircraft(std::string callsign, Mediator &m);
  void requestLanding(); void landed(); void requestTakeoff(); void tookOff();
  void receive(const std::string &msg);   // lưu tin nhắn nhận được để test
};
```

| Luật của tháp | Chi tiết |
| --- | --- |
| Chỉ có 1 đường băng | Tại một thời điểm chỉ một máy bay được sử dụng |
| Hạ cánh được ưu tiên hơn cất cánh | Hai hàng chờ riêng biệt |
| Đường băng trống | Tháp báo cho máy kế tiếp trong hàng |

```text
A xin hạ cánh -> A nhận "được hạ cánh"
B xin cất cánh -> B nhận "chờ"
C xin hạ cánh -> C nhận "chờ"
A báo đã hạ cánh -> C (ưu tiên hạ cánh) nhận "được hạ cánh", B vẫn chờ
```

**Ràng buộc:** `Aircraft` không được giữ tham chiếu tới `Aircraft` khác.

### Bài 2: Memento cho trình soạn thảo

```cpp
class Editor {
 public:
  void type(const std::string &s); void moveCursor(int pos); void select(int from, int to);
  class Memento { friend class Editor; /* private: text, cursor, selection */ };
  Memento save() const; void restore(const Memento &m);
};
class History { public: void push(Editor::Memento m); std::optional<Editor::Memento> pop(); };
```

**Ràng buộc:** `History` không đọc được nội dung của `Memento` (không có getter công khai).

```text
type "Hello"; save; type " World"; save; type "!"
restore 2 lần -> "Hello", con trỏ đúng vị trí lúc lưu
```

### Bài 3: Prototype và clone sâu (nâng cao)

1. `Shape` có hàm `virtual std::unique_ptr<Shape> clone() const = 0`. Viết `Circle`, `Rectangle` và `Group` (chứa một `vector<unique_ptr<Shape>>`).
2. `Group::clone()` phải clone sâu. Viết test: sửa bản clone thì bản gốc không đổi.
3. Viết `ShapeRegistry`: đăng ký mẫu theo tên, `create(name)` trả về một bản clone.
4. Cố tình viết bản clone nông cho `Group` (dùng `shared_ptr` để chia sẻ các con). Viết test cho thấy lỗi.
