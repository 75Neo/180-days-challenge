## Giới thiệu

Bài này học kernel quét ảnh và tầng gộp thu nhỏ.
Dùng để nhận diện ảnh nhanh hơn MLP rất nhiều.

## Kiến thức cần nhớ

### Tích chập

- Định nghĩa: kernel nhỏ trượt khắp ảnh để đo độ khớp mẫu.
- Cùng kernel dùng chung trọng số trên toàn ảnh.
- Ví dụ đời thường: như con tem dò khắp bản đồ tìm hình.
- Mẫu học ở góc trái vẫn nhận ra ở góc phải.
- Số tham số giảm mạnh so với nối đầy đủ.

### Stride và padding

- Kernel: cửa sổ nhìn rộng bao nhiêu mỗi lần.
- Stride: mỗi bước nhảy mấy điểm ảnh.
- Padding: có bọc viền để giữ kích thước biên không.
- Ví dụ đời thường: như bước chân dài thì mau hết sân.
- Stride lớn thì bản đồ đặc trưng co nhanh.

| Tham số | Tăng lên thì | Giảm xuống thì |
|---|---|---|
| Kernel | Nhìn rộng hơn | Nhìn chi tiết hơn |
| Stride | Ảnh ra nhỏ hơn | Ảnh ra lớn hơn |
| Padding | Giữ biên tốt hơn | Mất viền nhiều hơn |

### Pooling và phân cấp

- Định nghĩa: tóm tắt mỗi ô nhỏ thành 1 con số.
- Gộp cực đại giữ chi tiết nổi bật nhất mỗi ô.
- Tầng thấp bắt cạnh, tầng cao bắt mặt và vật.
- Ví dụ đời thường: như nhìn xa chỉ thấy hình lớn.
- Nhờ đó CNN vượt MLP trên ảnh thật.

## Ví dụ

- Input: ảnh 32x32, kernel 3x3, stride 1 -> Output: bản đồ ~30x30.
- Giải thích: trừ viền kernel nên nhỏ hơn ảnh gốc một chút.

```python
# Gộp cực đại trên ô 2x2
o = max([1, 5, 3, 2])  # giữ số nổi bật nhất
print(o)  # 5
```

## 💻 Bài tập

Ngôn ngữ: **Python 3** với NumPy cho Bài 1-2, **PyTorch** cho Bài 3. Nộp vào `day-096/`.

### Bài 1: Tích chập và gộp tự cài

| Hàm | Yêu cầu |
| --- | --- |
| `conv2d(x, k, stride=1, padding=0)` | `x`: `(H, W)`, `k`: `(kh, kw)`. Kích thước ra $\lfloor (H + 2p - kh) / s \rfloor + 1$ |
| `conv2d_multi(x, W, b, stride, padding)` | `x`: `(C_in, H, W)`, `W`: `(C_out, C_in, kh, kw)` |
| `maxpool2d(x, size=2, stride=2)` | |
| `im2col` (tùy chọn) | Tăng tốc bằng phép nhân ma trận |

```text
Ảnh 32x32, kernel 3x3, stride 1, padding 0 -> 30x30
Ảnh 32x32, kernel 3x3, stride 1, padding 1 -> 32x32
Ảnh 32x32, kernel 5x5, stride 2, padding 0 -> 14x14
maxpool 4x4 -> 2x2
```

Kết quả khớp `torch.nn.functional.conv2d` (lưu ý PyTorch tính cross-correlation, không lật kernel).

### Bài 2: Kernel phát hiện cạnh

1. Đọc ảnh xám. Áp kernel Sobel ngang, Sobel dọc, và làm mờ Gauss 5x5. Lưu 3 ảnh kết quả.
2. Tính độ lớn gradient $\sqrt{G_x^2 + G_y^2}$ và lưu ảnh cạnh.
3. Dịch ảnh sang phải 5 pixel. Chứng minh bản đồ đặc trưng cũng dịch 5 pixel (tính tương biến tịnh tiến).

### Bài 3: CNN nhỏ cho chữ số (nâng cao)

1. Dựng CNN bằng PyTorch: `Conv(1,16,3) - ReLU - MaxPool - Conv(16,32,3) - ReLU - MaxPool - Linear - 10`. Huấn luyện trên MNIST 3 epoch.
2. Dựng MLP có số tham số tương đương. So accuracy test.
3. Đếm tham số từng tầng bằng tay và so với `sum(p.numel())`.
4. Vẽ 16 kernel của tầng conv đầu tiên sau huấn luyện.
